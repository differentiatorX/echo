Works with your agent

Paste a link. Your agent does the rest.

Echo is a set of simple terminal commands with a built-in playbook, so any coding agent can drive it. The agent judges the moments, Echo cuts them, then the agent reviews and fixes every clip.

Time and tokens

Know the cost before you hit go.

Echo only sends your AI the transcript, never the video, so tokens grow with how long people talk, not with file size. Slide to your video and see what a run takes.

How you run it
Your computer
Time6-9 min
Tokens50-75k

    Estimates for a typical talking video. The first run on a new computer also downloads the speech model once (a few minutes). On a Claude plan, tokens count toward your usage limits rather than costing money per run. Agents re-read earlier steps as they work, so your app's own meter can show more than the content Echo sends.

    About five minutes

    It never downloads what it doesn't need.

    1. 1Prepare

      Captions, replay curve and comments. No video yet.

      seconds
    2. 2Judge

      Your agent reads the brief and scores every moment.

      about a minute
    3. 3Cut

      Only the chosen ranges download in 1080p.

      1 to 2 min
    4. 4Render

      Captions, reframing and zooms in one pass per clip.

      1 to 2 min
    5. 5Review

      The agent checks every clip and fixes weak ones.

      seconds each

    What the edit does

    Every clip leaves finished.

    Cold open

    The strongest line plays first, then a hard cut back to the start.

    Jump cuts and zooms

    Silences and filler words go. Framing shifts every few seconds.

    Big captions

    Word-by-word, ice blue active words, electric keywords.

    Speaker reframing

    Face-centered crops, split screen for two-person podcasts.

    Fix by command

    Trim the opening, rewrite the hook, change style in seconds.

    Trial reels

    Optionally show strangers first and let Instagram promote winners.

    Sound and music

    Whooshes on cuts, pops on keywords, your music ducked under the voice.

    Every format

    9:16 Reels, 4:5 feed, 1:1, all inside Instagram's safe zones.

    Covers and export

    Grid-safe covers with the hook, plus captions ready to paste, in one folder.

    Install

    One line. Everything set up.

    Installs Python, ffmpeg and Echo if they're missing, connects every AI agent on your computer, and checks it all works.
